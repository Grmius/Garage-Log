Garage Log GitHub Pages PWA. Upload the contents of this ZIP to the ROOT of your garage-log repository (not the enclosing folder). Go to Settings > Pages, select Deploy from a branch, main, /(root), Save. Wait for Pages to publish, open the HTTPS site on Samsung Chrome, choose Install app or Add to Home screen. User data is stored in browser localStorage on that device: export backups regularly. VIN photo recognition uses remote Tesseract JS CDN and online language assets; NHTSA decoding and ChatGPT require internet. The ChatGPT button copies a prompt and opens the ChatGPT website, not an embedded AI API. Auto specs only provides a web search, not trusted autofill.
